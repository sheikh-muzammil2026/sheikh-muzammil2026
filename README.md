## 🚀 About Me

I'm a **Full Stack Developer and Web Administrator** from Habiganj, Bangladesh, passionate about building modern, scalable, and user-friendly web applications.

I transitioned from an educational background into software development and now work on developing and maintaining real-world web applications using modern JavaScript technologies.

- 💻 **Professional Role:** Full Stack Developer & Web Administrator.
- 🕌 **Real-World Experience:** Developing and maintaining AimHabiganj, an ERP-based Madrasah Management System.
- ⚡ **Core Expertise:** Next.js, React.js, Node.js, Express.js, MongoDB, and REST APIs.
- 🔐 **Authentication:** Better Auth, JWT, role-based access control, and secure authentication systems.
- 🗄️ **Database:** MongoDB aggregation, MySQL, and database management.
- 🌐 **Web Administration:** Linux, Ubuntu, Apache, hosting, deployment, and server management.
- 🌱 **Currently Exploring:** Scalable application architecture, multi-tenant SaaS, and advanced backend development.
- 🎓 **Education:** Master of Arts (MA) in Islamic Studies, 2021.
- 📚 **Learning Journey:** Completed web development training through Programming Hero (Batch-13).

I enjoy solving real-world problems, learning new technologies, and continuously improving my development skills.

A real-world ERP-based Madrasah Management System designed to simplify educational administration.

- Role-based dashboards and secure authentication.
- AI-powered chatbot integration.

**Technologies:** Next.js, Node.js, Express.js, MongoDB, Better Auth, JWT.
